# NOIR – Tailwind CSS Fashion Landing Page

A modern, stylish and responsive **e-commerce fashion landing page** built with **Tailwind CSS**, custom JavaScript interactions, and semantic HTML.  
Perfect for showcasing collections, featured items, brand storytelling, and customer engagement.

--

🔗 **Live Demo:** https://pr-noir-tailwind.vercel.app/

--

## 🚀 Features

- ⚡ **Responsive design** — optimized for mobile, tablet, and desktop views  
- 🎨 **Tailwind CSS utility-first styling** for rapid UI development  
- 👚 **Product Collections with filtering**  
- 🏷️ Sections for Latest Collections, Testimonials, Featured Items, and Contact  
- 💬 Contact form UI included  
- 📦 Easy to customize and extend for your brand

--

## 🛠 Tech Stack

- **Tailwind CSS** – utility-first CSS framework  
- **HTML5 & JavaScript** – semantic markup and interactivity
